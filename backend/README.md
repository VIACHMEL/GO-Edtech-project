# Backend

Доски попыток, WebSocket и локальный запуск с PostgreSQL описаны в [инструкции по доске](../frontend/solve-board/README.md).

Язык: Go. Исполняемого кода пока нет.

Первая задача: выбрать версию Go, создать модуль, HTTP-сервер с health endpoint, тест и команды запуска. Затем добавить CI сборки, go test, go vet и проверки gofmt. Будущие области описаны в ../docs/architecture.md.
