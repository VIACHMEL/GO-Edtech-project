# GO-Edtech-project

Создаём единую EdTech-платформу для репетиторов: видеозанятия, интерактивная доска, банк заданий, расписание, финансовый учёт, аналитика и ИИ-ассистент.

## Текущий статус

Работают Go API и PostgreSQL, вход и регистрация через Django, профили, ученики,
группы и чтение банка в конструкторе. Регистрация сразу открывает кабинет.
Неподключённые разделы показывают сообщение; вымышленные данные удалены.
Полный цикл работ реализован в Go API, но ещё не подключён ко всем страницам.
Парсер и SVG → TikZ остаются обязательными отдельными частями MVP.

Утверждено: логика и данные на Go, интерфейс на Django/Python вместо Rust, источник первого парсера — Школково. Django получает данные через API Go, не управляет предметной БД и не принимает решения о правах. Парсер и SVG → TikZ входят в MVP. Инфраструктура и способ реализации модели пока не выбраны. См. [решение о Django](docs/decisions/001-django-presentation.md).

## Начать работу

Локальный запуск Go и Django: `bash run.sh --setup` при первом запуске,
затем `bash run.sh`. На Linux/WSL без DATABASE_URL создаётся отдельный локальный
PostgreSQL; в Windows Git Bash задайте DATABASE_URL подготовленной локальной БД.
Существующая БД автоматически не мигрируется. Подробнее: [локальный запуск](docs/quick-vps-release.md#1-локальная-разработка).
Открыть http://127.0.0.1:8080/login/, остановить — Ctrl+C.

1. Прочитать [состав MVP](docs/mvp.md) и [дорожную карту](docs/roadmap.md).
2. Изучить [архитектуру](docs/architecture.md), [модель данных](docs/data-model.md) и [открытые решения](docs/decisions/README.md).
3. Выбрать задачу из [стартового списка](docs/backlog.md).
4. Следовать [правилам участия](CONTRIBUTING.md). ИИ-помощникам также читать [AGENTS.md](AGENTS.md).

Клонирование:

```sh
git clone https://github.com/VIACHMEL/GO-Edtech-project.git
cd GO-Edtech-project
```

Для приватного репозитория нужен доступ через личный аккаунт GitHub.

Локальный запуск интерфейса (Python 3.12–3.14):

```sh
cd frontend
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python manage.py runserver 127.0.0.1:8000
```

Открыть http://127.0.0.1:8000/. Для регистрации, входа и кабинетов нужны Go и БД;
для общего запуска используйте `bash run.sh` из корня. Подробности — [frontend/README.md](frontend/README.md).

## Структура

- backend/ — Go API и серверная логика.
- frontend/ — Django страницы, оформление и клиент API Go.
- pipelines/ — импорт банка и обработка рисунков.
- docs/ — требования, контракты, решения и план.
- .github/ — шаблоны задач и Pull Request.

Описание [обработки SVG → TikZ](docs/svg-to-tikz.md) и [распределения работы семерых](docs/team.md).

Все функции исходной таблицы остаются в дорожной карте. Этапы — предложение по очередности, а не отказ от функций.

## Обновление HTTPS-стенда по SSH

```bash
bash deploy.sh --plan
bash deploy.sh
```

Скрипт берёт проверенный коммит из origin/main, не переключает локальную ветку,
собирает отдельный релиз на `/opt/go-edtech-stage`, сохраняет БД и файлы,
переключает только `edtech-stage-go` и `edtech-stage-django` и проверяет HTTPS.
Сайт: https://edtech.promodetector.top/. После новых миграций необходим отдельный
план; скрипт не применяет миграции и не импортирует банк автоматически.
См. [быстрый регламент](docs/quick-vps-release.md) и [первоначальное развёртывание](docs/deployment-vps.md).
