# GO-Edtech-project

Создаём единую EdTech-платформу для репетиторов: видеозанятия, интерактивная доска, банк заданий, расписание, финансовый учёт, аналитика и ИИ-ассистент.

## Текущий статус

Есть запускаемая заготовка интерфейса Django: страницы, макеты кабинетов, переадресации и тесты. Серверная логика Go, база данных, настоящий вход и CI сборки ещё не реализованы. Видеозанятия и финансовый учёт из исходного описания требуют отдельного уточнения требований.

Утверждено: логика и данные на Go, интерфейс на Django/Python вместо Rust, источник первого парсера — Школково. Django получает данные через API Go, не управляет предметной БД и не принимает решения о правах. Парсер и SVG → TikZ входят в MVP. Инфраструктура и способ реализации модели пока не выбраны. См. [решение о Django](docs/decisions/001-django-presentation.md).

## Начать работу

1. Прочитать [состав MVP](docs/mvp.md) и [дорожную карту](docs/roadmap.md).
2. Изучить [архитектуру](docs/architecture.md), [модель данных](docs/data-model.md) и [открытые решения](docs/decisions/README.md).
3. Выбрать задачу из [стартового списка](docs/backlog.md).
4. Следовать [правилам участия](CONTRIBUTING.md). ИИ-помощникам также читать [AGENTS.md](AGENTS.md).

Клонирование:

```sh
git clone https://github.com/VIACHMEL/GO-Edtech-project.git
cd GO-Edtech-project
```

Для приватного репозитория нужен доступ через личный аккаунт GitHub.

Локальный запуск интерфейса (Python 3.12–3.14):

```sh
cd frontend
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python manage.py runserver 127.0.0.1:8000
```

Открыть http://127.0.0.1:8000/. База и Go для просмотра макетов не нужны. Это локальная заготовка, не готовая платформа. Подробные команды, настройки и ограничения — [frontend/README.md](frontend/README.md).

## Структура

- backend/ — Go API и серверная логика.
- frontend/ — Django страницы, оформление и клиент API Go.
- pipelines/ — импорт банка и обработка рисунков.
- docs/ — требования, контракты, решения и план.
- .github/ — шаблоны задач и Pull Request.

Описание [обработки SVG → TikZ](docs/svg-to-tikz.md) и [распределения работы семерых](docs/team.md).

Все функции исходной таблицы остаются в дорожной карте. Этапы — предложение по очередности, а не отказ от функций.
