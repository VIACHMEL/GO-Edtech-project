# Дорожная карта

Все функции таблицы сохранены. Состав этапов — предложение; стек и включение парсера/SVG → TikZ в MVP заданы владельцем.

| Возможность | MVP | Далее |
| --- | --- | --- |
| Банк заданий | Парсер Школково, исходные материалы, фильтры, версии, SVG → TikZ | Другие источники, предметы, расширение покрытия |
| Конструктор | Ручной выбор, простая выборка по фильтрам, назначение, срок | Более сложные правила генерации |
| Проверка | Короткие ответы автоматически, развёрнутые вручную; подтверждение учителем | Расширение правил |
| Наблюдение за занятием | Не входит | Этап 2: текущая задача, сдача, предварительная проверка, восстановление соединения |
| Статистика | История и баллы | Этап 2: ошибки по темам, динамика, время |
| Рекомендации | Не входят | Этап 3: правила по ошибкам, индивидуальные варианты, затем оценка моделей |
| ИИ-проверка | Фото принимаются для ручной проверки | Этап 3: оценка по критериям с контролем преподавателя |
| Доска | Не входит | Этап 2: совместное рисование, изображения/PDF, области задач, сохранение и экспорт |
| Расписание | Только сроки работ | Этап 2: создание/перенос занятий; этап 3: Google Calendar |
| Группы | Состав, назначение, отдельные ответы | Этап 2: совместные занятия |
| Кабинеты | Приглашения, работы, результаты | Расширение по мере готовности функций |

## Этап 0: подготовка

Общий контракт, выбор первого предмета/экзамена, запускаемый каркас Go и Django, CI. Заготовка Django есть; настоящий вход, интеграция с Go и автоматическая сборка ещё нужны. Параллельно — изучение структуры банка Школково и выборки SVG; разработка парсера не должна ждать готовности всех экранов.

## Этап 1: MVP

Два направления: импорт и конвертация рисунков; выполнение и проверка работ. Они сходятся на назначении реальных импортированных задач. Условия выпуска — docs/mvp.md и отдельный отчёт качества TikZ.

## Этап 2: занятия

Наблюдение в реальном времени, доска, расписание, расширенная статистика. Доску проверить на группе до 10 человек, включая обрыв соединения и восстановление сохранённого состояния.

## Этап 3: автоматизация

Рекомендации, ИИ-проверка, календарная интеграция, масштабирование банка. Использовать историю и проверенные данные предыдущих этапов.

## Дополнительные идеи исходного README

Видеозанятия и финансовый учёт сохранены в продуктовой перспективе. В таблице их подробных требований нет; сначала уточнить сценарии и этап. ИИ-ассистент пока раскрывается через рекомендации и проверку; отдельный чат не считается утверждённым требованием.

Даты не назначены: неизвестны доступное время команды, объём данных и результаты эксперимента конвертации.
