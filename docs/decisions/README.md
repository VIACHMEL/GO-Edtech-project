# Решения

## Зафиксировано владельцем

- Backend: Go.
- Frontend: Rust.
- Репозиторий: VIACHMEL/GO-Edtech-project.
- Первый источник банка: Школково.
- Парсер и SVG → TikZ входят в MVP.
- Все функции таблицы остаются в плане.
- Участников пока не добавлять.
- Подготовительные файлы разрешено загрузить непосредственно в main.

## Открыто

- Rust-фреймворк и способ сборки/доставки интерфейса.
- Первый предмет, экзамен и точный раздел источника.
- База данных, файловое хранилище и размещение.
- Покрытие SVG → TikZ, модель, метод обучения, бюджет, оборудование и метрики.
- Условия повторной сдачи и изменения групп.
- Конкретные требования к видеозанятиям и финансовому учёту.

Для значимого выбора создать отдельный Markdown-файл: статус, проблема, варианты, решение, последствия и дата. Предложение становится принятым только после согласования.
