## P02: критерии заготовки Django

- [x] Локальный запуск без Go и базы; страницы и статические файлы.
- [x] Главная, навигация, публичные макеты обоих кабинетов.
- [x] Закрытые страницы направляют на вход; макеты не выдают личность.
- [x] Безопасная обработка next, канонические адреса и страницы ошибок.
- [x] /health/ отдельно от /ready/ для Go; сбой не означает успех.
- [x] Тесты поведения, настройки окружения, инструкции и решение о замене Rust.
- [ ] Контракт входа и интеграция с работающим Go.
- [ ] CI и промышленное размещение.

Готовность заготовки не закрывает P02 целиком и не означает готовность MVP.
