# Документация пакета `db`

Пакет `db` отвечает за подключение к PostgreSQL, сохранение и получение
задач, а также управление связанными с версиями задач артефактами.

## Структура базы данных

База данных PostgreSQL состоит из трёх основных таблиц: `tasks`, `task_versions` и `task_artifacts`.

### 1. Таблица `tasks`

Хранит основную информацию о заданиях и ссылку на их текущую версию.

| Поле | Тип | Описание |
|---|---|---|
| `id` | `BIGSERIAL` | Первичный ключ |
| `source_url` | `TEXT` | URL источника задания |
| `source_site` | `TEXT` | Название сайта-источника |
| `subject` | `TEXT` | Предмет |
| `task_number` | `INT` | Номер задания |
| `year` | `INT` | Год |
| `exam_type` | `TEXT` | Тип экзамена |
| `task_type` | `TEXT` | Тип задания |
| `metadata` | `JSONB` | Дополнительные данные в формате JSON |
| `current_version_id` | `BIGINT` | ID текущей версии задания |
| `created_at` | `TIMESTAMPTZ` | Дата создания записи |
| `updated_at` | `TIMESTAMPTZ` | Дата последнего обновления |

**Особенности:**
- `source_url` уникален для каждой задачи.
- Для `subject` и `year` созданы индексы для ускорения поиска.
- Для `metadata` используется GIN-индекс.

### 2. Таблица `task_versions`

Хранит версии содержимого заданий. Каждое задание может иметь несколько версий.

| Поле | Тип | Описание |
|---|---|---|
| `id` | `BIGSERIAL` | Первичный ключ |
| `task_id` | `BIGINT` | ID задания из `tasks` |
| `content_text` | `TEXT` | Текст задания |
| `answer` | `TEXT` | Ответ |
| `solution` | `TEXT` | Решение |
| `content_hash` | `TEXT` | Хэш содержимого |
| `version_number` | `INT` | Номер версии |
| `created_at` | `TIMESTAMPTZ` | Дата создания версии |

**Особенности:**
- `task_id` связан с `tasks.id`.
- При удалении задания все его версии удаляются автоматически (`ON DELETE CASCADE`).
- Для одной задачи не может существовать двух версий с одинаковым `content_hash`.
- Пара `task_id + version_number` также уникальна.

**Обновление текущей версии:**

При добавлении или обновлении записи в `task_versions` срабатывает триггер `trigger_update_current_version`. Он вызывает функцию `update_current_version()`, которая записывает ID изменённой версии в поле `tasks.current_version_id`.

### 3. Таблица `task_artifacts`

Хранит файлы и внешние ресурсы, связанные с конкретными версиями заданий.

| Поле | Тип | Описание |
|---|---|---|
| `id` | `BIGSERIAL` | Первичный ключ |
| `task_version_id` | `BIGINT` | ID версии задания |
| `type` | `TEXT` | Тип артефакта |
| `artifact_key` | `TEXT` | Уникальный ключ артефакта |
| `file_path` | `TEXT` | Путь к локальному файлу |
| `external_url` | `TEXT` | URL внешнего ресурса |
| `original_filename` | `TEXT` | Исходное имя файла |
| `mime_type` | `TEXT` | MIME-тип файла |
| `file_size` | `BIGINT` | Размер файла |
| `checksum` | `TEXT` | Контрольная сумма SHA-256 |
| `storage_type` | `TEXT` | Тип хранилища |
| `status` | `TEXT` | Статус обработки |
| `error_message` | `TEXT` | Описание ошибки |
| `created_at` | `TIMESTAMPTZ` | Дата создания записи |
| `updated_at` | `TIMESTAMPTZ` | Дата последнего обновления |

**Допустимые типы артефактов:**
- `image` — изображение;
- `svg` — SVG-графика;
- `tikz` — графика TikZ;
- `attachment` — вложение;
- `preview` — предварительный просмотр.

**Типы хранилища:**
- `local` — локальное хранение;
- `s3` — S3-хранилище;
- `external` — внешний ресурс.

**Статусы артефактов:**
- `pending` — ожидает обработки;
- `done` — обработка завершена;
- `failed` — произошла ошибка;
- `abandoned` — обработка отменена;
- `external` — ресурс хранится по внешней ссылке.

**Особенности:**
- `task_version_id` связан с `task_versions.id`.
- При удалении версии все её артефакты удаляются автоматически.
- Комбинация `task_version_id + type + artifact_key` уникальна.
- Для статуса `done` обязательно наличие пути к файлу или внешнего URL при `storage_type = 'external'`.
- Для ускорения запросов созданы индексы по `task_version_id`, `status` и `external_url`.

### 4. Связи между таблицами

Структура связей:

```text
tasks
  |
  | 1:N
  |
task_versions
  |
  | 1:N
  |
task_artifacts
```

- Одна задача (`tasks`) может иметь несколько версий (`task_versions`).
- Каждая версия может содержать несколько артефактов (`task_artifacts`).
- `tasks.current_version_id` указывает на актуальную версию задания.
- Удаление задачи приводит к удалению всех её версий и связанных артефактов.

### 5. Миграции базы данных

Структура БД формируется тремя последовательными миграциями:

| Миграция | Назначение |
|---|---|
| `000001_init_tasks` | Создание основной таблицы `tasks` |
| `000002_versions_and_artifacts` | Добавление версионирования заданий и таблицы артефактов |
| `000003_artifacts_development` | Добавление поддержки внешних ресурсов, контрольных сумм, MIME-типов, размеров файлов и расширенных статусов |

Для каждой миграции предусмотрен файл `down.sql`, выполняющий откат внесённых изменений.

## `db.go` --- подключение к БД

### Константы

  Константа            Значение Назначение
  ------------------ ---------- -------------------------------------------
  `maxConnections`         `10` Максимальное количество соединений в пуле

### Структура `DB`

  Поле     Тип               Назначение
  -------- ----------------- ---------------------------
  `Pool`   `*pgxpool.Pool`   Пул соединений PostgreSQL

### Функции

#### `New(ctx context.Context, dsn string) (*DB, error)`

Создаёт подключение к БД и пул соединений.

-   `ctx` --- контекст выполнения.
-   `dsn` --- строка подключения к PostgreSQL.
-   Возвращает `*DB` и `nil`, если пул создан и проверка соединения
    прошла успешно.
-   Возвращает `nil` и ошибку, если не удалось разобрать DSN, создать
    пул или выполнить `Ping`.

Параметры пула: не более 10 соединений, время жизни соединения --- 1
час.

#### `(db *DB) Close()`

Закрывает пул соединений. Возвращаемого значения нет.

### Внутренняя функция

#### `generateHash(t *Task) string`

Вычисляет SHA-256-хэш строки, составленной из `Subject`, `TaskNumber` и
`ContentText` в формате `предмет:номер:текст`.

-   `t` --- задача.
-   Возвращает хэш в шестнадцатеричном виде.

## `tasks.go` --- операции с задачами и артефактами

### Внутренние константы

  Константа              Значение Назначение
  -------------------- ---------- ------------------------------------
  `defaultTaskLimit`         `20` Лимит выборки по умолчанию
  `minFilterLimit`            `0` Нижняя граница допустимого лимита
  `maxFilterLimit`          `100` Верхняя граница допустимого лимита

Если `TaskFilter.Limit` не входит в диапазон `1–100`, используется
значение `20`.

### Проверка и подготовка задач

#### `validateTask(t *Task) error`

Проверяет обязательные поля задачи.

-   `t` --- проверяемая задача.
-   Возвращает `nil`, если проверка пройдена.
-   Возвращает ошибку `ErrValidation`, если `SourceURL`, `Subject` или
    `ContentText` пусты либо `TaskNumber` отрицательный.

#### `prepareTask(t *Task)`

Нормализует строковые поля задачи: удаляет пробелы по краям у
`SourceURL`, `SourceSite`, `Subject`, `ContentText`, `Answer` и
`Solution`. Инициализирует `Metadata`, если она равна `nil`, и
рассчитывает `ContentHash`.

-   `t` --- задача.
-   Ничего не возвращает.

#### `validateAndPrepareAllTasks(tasks []*Task) error`

Подготавливает и проверяет все задачи в срезе.

-   `tasks` --- список задач.
-   Возвращает `nil`, если все задачи прошли проверку.
-   Возвращает ошибку при первой невалидной задаче; в сообщении
    указывается её `SourceURL`.

### Подготовка SQL-запросов и чтение результатов

#### `buildTaskArgs(t *Task) []any`

Формирует аргументы для `upsertTaskQuery` в порядке SQL-параметров.

-   `t` --- задача.
-   Возвращает срез аргументов для полей задачи и её версии.

#### `buildBatch(tasks []*Task) *pgx.Batch`

Формирует пакет SQL-запросов на добавление задач.

-   `tasks` --- список подготовленных задач.
-   Возвращает пакет `pgx.Batch`.

#### `executeBatch(ctx context.Context, transaction pgx.Tx, batch *pgx.Batch, count int) error`

Выполняет пакет запросов внутри переданной транзакции.

-   `ctx` --- контекст.
-   `transaction` --- активная транзакция.
-   `batch` --- пакет запросов.
-   `count` --- количество результатов, которые нужно обработать.
-   Возвращает `nil` при успешном выполнении всех запросов; иначе ---
    ошибку выполнения.

#### `scanTask(row pgx.Row) (*Task, error)`

Считывает одну строку результата SQL-запроса и заполняет структуру
`Task`.

-   `row` --- строка результата запроса.
-   Возвращает указатель на `Task` и `nil` при успехе; иначе --- `nil` и
    ошибку чтения.

#### `rowsToTasks(rows pgx.Rows) ([]*Task, error)`

Преобразует строки результата SQL-запроса в список задач.

-   `rows` --- набор строк результата.
-   Возвращает список задач при успехе; иначе --- `nil` и ошибку чтения
    или итерации.

### Проверка артефактов

#### `validateArtifactKey(key string) (string, error)`

Проверяет ключ артефакта.

-   `key` --- ключ артефакта.
-   Если ключ пустой, заменяет его на `main`.
-   Допустимы 1--64 символа: латинские буквы, цифры, `_` и `-`.
-   Возвращает нормализованный ключ и `nil` при успехе; иначе --- ключ и
    `ErrValidation`.

#### `validateArtifactType(typ string) error`

Проверяет тип артефакта.

-   `typ` --- тип артефакта.
-   Допустимые значения: `image`, `svg`, `tikz`, `attachment`,
    `preview`.
-   Возвращает `nil` при успехе или `ErrValidation` для неизвестного
    типа.

#### `validateArtifactStatus(s string) error`

Проверяет статус артефакта.

-   `s` --- статус.
-   Допустимые значения: `pending`, `done`, `failed`, `abandoned`,
    `external`.
-   Возвращает `nil` при успехе или `ErrValidation` для неизвестного
    статуса.

#### `isUniqueViolation(err error) bool`

Проверяет, является ли ошибка PostgreSQL нарушением уникальности.

-   `err` --- ошибка БД.
-   Возвращает `true`, если код PostgreSQL равен `23505`; иначе `false`.

### Публичные методы `DB`: задачи

#### `(db *DB) AddTask(ctx context.Context, t *Task) (*AddTaskResult, error)`

Добавляет задачу или обновляет существующую по `SourceURL`, сохраняя
версию содержимого.

-   `ctx` --- контекст.
-   `t` --- задача.
-   Возвращает `AddTaskResult` с ID задачи, ID версии, номером версии и
    признаком создания новой версии.
-   Возвращает ошибку при невалидных данных или ошибке БД.
-   При нарушении уникальности номера версии повторяет запрос до трёх
    раз.

#### `(db *DB) AddTasks(ctx context.Context, tasks []*Task) error`

Добавляет список задач в одной транзакции.

-   `ctx` --- контекст.
-   `tasks` --- список задач.
-   Возвращает `nil` при успешном выполнении и фиксации транзакции.
-   Пустой список считается успешным случаем: возвращается `nil`.
-   Возвращает ошибку при валидации, начале транзакции, выполнении
    запросов или фиксации транзакции. При ошибке транзакция
    откатывается.

#### `(db *DB) GetTask(ctx context.Context, id int64) (*Task, error)`

Получает задачу по ID вместе с данными её текущей версии.

-   `ctx` --- контекст.
-   `id` --- ID задачи.
-   Возвращает `*Task` и `nil`, если задача найдена.
-   Возвращает `nil` и `ErrNotFound`, если записи нет; при ошибке БД
    возвращает обёрнутую ошибку.

#### `(db *DB) GetTasksByIDs(ctx context.Context, ids []int64) ([]*Task, error)`

Получает задачи по списку ID вместе с данными текущих версий.

-   `ctx` --- контекст.
-   `ids` --- список ID задач.
-   Возвращает список найденных задач.
-   Для пустого списка ID возвращает пустой срез и `nil`.
-   Возвращает ошибку при выполнении запроса или чтении результатов.

#### `(db *DB) ListTasks(ctx context.Context, filter TaskFilter) ([]*Task, error)`

Возвращает случайные задачи, соответствующие фильтрам.

-   `ctx` --- контекст.
-   `filter` --- предмет, год, номер и тип задания, а также лимит.
-   Пустые строковые поля и числовые значения `0` отключают
    соответствующий фильтр.
-   Если лимит не входит в диапазон `1–100`, применяется лимит `20`.
-   Возвращает список задач или ошибку запроса/чтения.

### Публичные методы `DB`: артефакты

#### `(db *DB) CreatePendingArtifact(ctx context.Context, versionID int64, typ, key, externalURL, originalFilename string) error`

Создаёт запись о будущем артефакте со статусом `pending`. Вызывается до
скачивания или рендеринга.

-   `ctx` --- контекст.
-   `versionID` --- ID версии задачи.
-   `typ` --- тип артефакта.
-   `key` --- ключ артефакта; пустое значение заменяется на `main`.
-   `externalURL` --- URL внешнего ресурса; если пустой, используется
    локальное хранение.
-   `originalFilename` --- исходное имя файла.
-   Возвращает `nil` при успешной записи или обновлении; иначе ---
    ошибку валидации или БД.
-   Если запись уже существует, она обновляется. Завершённый артефакт с
    непустой контрольной суммой сохраняет статус `done`, в остальных
    случаях получает `pending`.

#### `(db *DB) CompleteArtifact(ctx context.Context, versionID int64, typ, key, filePath, mimeType string, fileSize int64, checksum string) error`

Отмечает локальный артефакт как готовый. Вызывается после атомарного
перемещения файла в конечное место.

-   `ctx` --- контекст.
-   `versionID` --- ID версии задачи.
-   `typ` --- тип артефакта.
-   `key` --- ключ артефакта; пустое значение заменяется на `main`.
-   `filePath` --- путь к готовому файлу.
-   `mimeType` --- MIME-тип файла.
-   `fileSize` --- размер файла.
-   `checksum` --- контрольная сумма.
-   Возвращает `nil` при успешном обновлении.
-   Возвращает `ErrValidation`, если `filePath` или `checksum` пусты;
    `ErrNotFound`, если запись артефакта не найдена; иначе --- ошибку
    БД.

#### `(db *DB) UpdateArtifactStatus(ctx context.Context, versionID int64, typ, key, status string) error`

Изменяет статус существующего артефакта.

-   `ctx` --- контекст.
-   `versionID` --- ID версии задачи.
-   `typ` --- тип артефакта.
-   `key` --- ключ артефакта; пустое значение заменяется на `main`.
-   `status` --- новый статус.
-   Возвращает `nil` при успешном обновлении.
-   Возвращает `ErrValidation` при неизвестном статусе или некорректном
    ключе, `ErrNotFound` при отсутствии записи, иначе --- ошибку БД.
-   При статусе, отличном от `failed`, очищает `error_message`.

#### `(db *DB) MarkExternal(ctx context.Context, versionID int64, typ, key, externalURL, mimeType string) error`

Помечает артефакт как внешний ресурс, хранящийся вне локального
хранилища. Подходит, например, для видео, аудио и больших файлов.

-   `ctx` --- контекст.
-   `versionID` --- ID версии задачи.
-   `typ` --- тип артефакта.
-   `key` --- ключ артефакта; пустое значение заменяется на `main`.
-   `externalURL` --- обязательный URL внешнего ресурса.
-   `mimeType` --- MIME-тип ресурса.
-   Возвращает `nil` при успешном обновлении.
-   Возвращает `ErrValidation`, если тип или ключ некорректны либо URL
    пуст; `ErrNotFound`, если запись не найдена; иначе --- ошибку БД.

#### `(db *DB) FailArtifact(ctx context.Context, versionID int64, typ, key, errMsg string) error`

Помечает артефакт как неудачно обработанный.

-   `ctx` --- контекст.
-   `versionID` --- ID версии задачи.
-   `typ` --- тип артефакта.
-   `key` --- ключ артефакта; пустое значение заменяется на `main`.
-   `errMsg` --- описание ошибки.
-   Возвращает `nil` при успешном обновлении.
-   Возвращает `ErrValidation` при некорректном ключе, `ErrNotFound` при
    отсутствии записи, иначе --- ошибку БД.

#### `(db *DB) GetArtifactsByVersionID(ctx context.Context, versionID int64) ([]*TaskArtifact, error)`

Получает все артефакты конкретной версии задачи.

-   `ctx` --- контекст.
-   `versionID` --- ID версии задачи.
-   Возвращает список `*TaskArtifact`, отсортированный по типу и ключу.
-   Если артефактов нет, возвращает пустой список и `nil`.
-   Возвращает ошибку при выполнении запроса, чтении записи или итерации
    результатов.

## Примечания

-   `Task` объединяет поля основной задачи и данные её текущей версии.
-   `TaskArtifact` относится к конкретной версии задачи, а не просто к
    задаче.
-   `AddTask` и `AddTasks` используют подготовку и валидацию данных
    перед записью.
-   Методы артефактов работают с парой `versionID + type + key`.
-   В представленных файлах нет описания SQL-схемы таблиц и миграций;
    документация описывает только структуры и поведение Go-кода.
