# MVP

Статус: рабочее предложение по объёму. Обязательные решения владельца: Go backend, Rust frontend, парсер Школково и SVG → TikZ в первой версии.

## Два результата первой версии

1. Импортировать задачи Школково с рисунками, получить проверенные TikZ-представления для согласованных классов рисунков.
2. Провести полный цикл домашней работы: приглашение → назначение → ответы → проверка → опубликованный результат.

Первый предмет, экзамен и объём банка нужно выбрать. Целевой сценарий — преподаватель и минимум два тестовых ученика.

## Входит

- Учётные записи, роли, приглашения, группы, серверная проверка доступа.
- Парсер одного источника, сохранение ID/URL, повторный импорт без дублей, версии задач и исходных материалов.
- Банк с фильтрами и конструктор: ручной выбор и простая генерация по согласованным фильтрам.
- SVG → TikZ: выборка, оценка базовых подходов, подготовка парных данных; обучение/дообучение модели остаётся планируемой задачей. Способ и бюджет уточняются экспериментом.
- Хранение оригинала, проверка конвертации и просмотр результата перед публикацией.
- Назначение ученику/группе со сроком, сохранение черновиков, ответы и фотографии решений.
- Автопроверка согласованных коротких ответов, ручная проверка и комментарии, подтверждение результата преподавателем.
- История работ и базовые баллы.

## Приёмка

- Повторный импорт не создаёт дублей; сбой не публикует частично импортированную задачу.
- Опубликованные задачи содержат проверенные условия, ответы при наличии и рисунки.
- Для TikZ утверждены поддерживаемые классы, метрики и численные пороги. Есть отдельная тестовая выборка, отчёт и проверенные результаты. Одного прототипа генерации недостаточно.
- Ошибки конвертации не теряют оригинал и не подменяют рисунок непроверенной версией.
- Оба ученика выполняют общую работу, но имеют отдельные ответы и результаты.
- Повторная сдача запроса не дублирует результат; после сдачи изменения ограничены согласованными правилами.
- Преподаватель подтверждает результат, ученик видит его и комментарии.
- Чужие ответы недоступны через подмену ID; обновление страницы и перезапуск сервера сохраняют данные.
- Полный сценарий покрыт проверкой; пилотный преподаватель проходит его самостоятельно.

Сроки работ не заменяют расписание. Фотографии для ручной проверки не означают готовность ИИ-проверки. Следующие функции перечислены в roadmap.md.
