# Работа команды из семи человек

Это будущие зоны ответственности, не назначения конкретным людям. Приглашения пока не отправляются.

| Зона | Первый результат |
| --- | --- |
| 1. Координация и инфраструктура | Каркас, общие контракты, CI |
| 2. Пользователи и группы | Роли, приглашения и доступ |
| 3. Импорт и каталог | Парсер Школково, версии, фильтры |
| 4. SVG → TikZ | Выборка, метрики, конвертация, обучение и проверка |
| 5. Работы и результаты | Назначения, попытки, автоматическая и ручная проверка |
| 6. Django интерфейс преподавателя | Каталог, конструктор, проверка через API Go |
| 7. Django интерфейс ученика | Выполнение, вложения и результаты через API Go |

Интерфейсы могут начинаться на согласованных тестовых данных. Общие структуры и контракты согласовываются прежде, чем несколько участников реализуют зависимые части.

Один ответственный на задачу, помощь других разрешена. Каждый проверяет собственный код; второй участник проводит review. Все важные решения хранятся в репозитории, потому что личные чаты ИИ не являются общим контекстом.
