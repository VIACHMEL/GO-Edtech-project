# Контракты

- [Хранение вариантов](worksheets-storage.md).
- [Назначения, попытки и ответы](learning-storage.md).

Перед параллельной реализацией frontend/backend согласовать OpenAPI-контракт и тестовые ответы. Сейчас конкретных endpoints Go нет. Django маршруты и граница интеграции описаны в [django-frontend.md](django-frontend.md); они не являются API Go.

Для каждой операции описать:
- метод, путь, роли и проверку доступа к объекту;
- поля запроса/ответа, обязательность, формат ID и времени;
- ошибки с машинным кодом и понятным текстом;
- пагинацию/фильтры, повторные запросы и допустимые переходы состояний;
- правила получения вложений и публикации результата.

Начать с приглашений, каталога, создания работы, назначения, черновика ответа, сдачи и проверки.
Отдельно описать формат результата импорта и задания на конвертацию: source ID, asset ID, версия обработки, статус, ошибка, ссылки на артефакты.

Будущие события занятий и доски получают версию, ID события, правила переподключения и восстановления состояния.
