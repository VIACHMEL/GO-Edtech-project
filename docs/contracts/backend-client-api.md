# Справочник JSON-ответов Go для текущих страниц Django

Статус: проект контрактов чтения под существующий интерфейс, 10 ноября 2026 года.
**HTTP API Go пока нет.** Все `/api/v1/...` ниже — предлагаемые адреса. Форматы
ответов взяты из фактических результатов `frontend/backend_client.py`, а не из
сериализации Go-моделей БД. Страницы пока используют demo-функции без сети.

## Как пользоваться справочником

Для каждого запроса указаны потребитель, параметры, состав выборки, полный JSON
успешного ответа и происхождение полей. Все запросы GET, **без JSON-тела**;
параметры передаются в URL. Успех — HTTP 200 с приведённым JSON **без обёртки data**.
Общая таблица полей именованного типа применяется при каждом его вложении:
например, `students[].assignments[].deadline` = Student → AssignmentSummary → deadline.

Содержание: [профиль преподавателя](#api-1), [профиль ученика](#api-2),
[обзор преподавателя](#api-3), [ученики](#api-4), [группы](#api-5),
[проверка](#api-6), [конструктор](#api-7), [календарь преподавателя](#api-8),
[обзор ученика](#api-9), [календарь ученика](#api-10), [назначения](#api-11),
[комментарии](#api-12), [статистика](#api-13), [решение варианта](#api-14).

### Обозначения источников

- **Есть**: колонка или определённое преобразование уже доступны. HTTP-сборки ещё нет.
- **Частично**: есть часть связей/колонок, но не весь объект или правило.
- **Оформление**: подпись, относительный URL, календарная ячейка либо координаты графика;
  отдельной колонки БД не требуется. Это не новое предметное правило.
- **Нет**: нужной сущности или согласованного расчёта нет. Это блокер реального ответа,
  а не разрешение вернуть demo-значение, ноль или пустую строку вместо неизвестного.

Все имена, даты, баллы и ID в примерах — **вымышленные значения из текущего клиента**.
Префиксы s1/g1/t1/w1 показывают формат demo-ID, не требуют таких префиксов в БД:
реальные BIGINT передаются строками последовательно во всех ссылках.
Строки дат в JSON — текущие подписи интерфейса, не даты RFC 3339.
Ноябрь 2026 и 3 ноября зафиксированы в demo; правило часового пояса/локализации
для реальных дат ещё необходимо согласовать.

Форматы фиксируют нынешнюю потребность страниц, включая оформление. Это не перенос
правил в Django: состояние, доступ и предметные агрегаты определяет Go.
Новые поля и пагинация здесь не добавляются, массивы соответствуют текущему клиенту.

### Доступ и отсутствие данных

Каждый запрос работает от подтверждённого текущего пользователя. Механизм сеанса
ещё не реализован и этим справочником не выбирается. Go ограничивает выборки
своим преподавателем/учеником, а не переданным из браузера owner ID.
Предлагаемые общие ошибки: 401 без подтверждённой личности, 403 для неверной роли,
404 для отсутствующего или чужого адресуемого объекта, 503 при невозможности собрать
реальные обязательные данные. Тело ошибки — `{"error":{"code":"...","message":"..."}}`;
это отдельное предложение, не успешный DTO и не результат demo-функции.

Пустой доступный список — 200 и пустой массив с сохранением остальных полей ответа.
Нет источника данных — не то же самое, что достоверно пустой список.
Одиночные next_lesson/last_comment не поддерживают отсутствие в текущих шаблонах:
не добавлять null молча; такие случаи требуют отдельного изменения контракта/шаблона.

`/` (навигация) и `/register/` сейчас не вызывают backend-клиент. Создание группы,
регистрация, приглашения, сохранение/сдача ответов и публикация — запросы записи;
они не входят в этот справочник. Календарь/оплаты описаны только как потребности
существующих экранов, это не расширяет утверждённый MVP.

## Общие структуры и источники полей

Основные подтверждённые таблицы: users, teacher_students, groups, group_members,
tasks, task_versions, task_artifacts, invitations. Названия будущих сущностей
«занятие», «назначение», «попытка», «проверка», «платёж» ниже — **логические источники**,
не названия уже существующих таблиц. Миграция 000002 перенесла content_text,
answer и solution из tasks в task_versions; нельзя брать их из старой схемы tasks.
В API не передаются password_hash, token_hash и произвольный tasks.metadata.
