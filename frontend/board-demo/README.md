# Прототип доски

Из корня репозитория, в PowerShell:

```powershell
cd frontend/board-demo
npm ci
npm run build
cd ../../backend
go run ./cmd/board-demo
```

Откройте [Анну](http://127.0.0.1:8092/?actor=anna) и [преподавателя](http://127.0.0.1:8092/?actor=teacher) в двух окнах. У преподавателя выберите попытку Анны.

1. Нарисуйте фигуру в любом окне. Фигура появится в другом.
2. Переключитесь с задания 1 на задание 2. Рисунок останется на общей доске тестовой части. У задания 3 отдельная доска.
3. У преподавателя выберите Ивана. Откроется доска его попытки. Вернитесь к Анне, чтобы продолжить просмотр её решения.
4. Сдайте попытку в окне Анны. Режим просмотра включится в обоих окнах. Откройте вторую попытку и проверьте, что её доски пусты. Для появления второй попытки в списке преподавателя нажмите «Обновить».

Сервер слушает только `127.0.0.1`. Роли, условия, части экзамена и лимит в две попытки заданы тестовыми данными. Выбранная роль передаётся в URL. Для запуска нужен Node.js 20.19+ или 22.12+, npm и Go из версии, указанной в `backend/go.mod`.

Go сохраняет доски и состояния попыток в `backend/.board-demo.json`. После перезагрузки вкладка получает последнюю сохранённую версию. Для отдельного набора данных задайте путь флагом `-state`. Изменения без подтверждения сервера при разрыве связи могут потеряться. При правках разных объектов сервер сохраняет оба изменения. Для одного и того же объекта применяется последняя полученная правка.

В этом прототипе поддерживаются рисунки и текст Excalidraw. Загрузка файлов и офлайн-редактирование требуют отдельной интеграции. Для подключения к платформе нужны пользовательская сессия Go, выдача реальных условий и частей экзамена и хранение досок в PostgreSQL. Страницы Django смогут подключать тот же редактор после появления этих контрактов.
