# Школково: математика ЕГЭ и ОГЭ — экспериментальный парсер

Парсер читает сохранённую **отрисованную** HTML-страницу с заданиями. Он экспериментальный: разметка взята с одной изученной страницы, не со всех разделов. Получение HTML из сети автоматически пока не реализовано: страница при прямом запросе ответила 503/проверкой браузера. Парсер не обходит проверку или авторизацию.

На странице графиков браузер загрузил SVG через `/api/latex-service/v1/GetSession/...`. Одна проверенная ссылка отдельно вернула HTTP 200, `image/svg+xml`, 15806 байт без передачи браузерной сессии. Это не подтверждает долговечность ссылок или доступность всех рисунков. Оригиналы здесь не скачиваются.

Формулы и рисунки могут быть SVG. Парсер включает alt в текст в исходном порядке, а URL — в `metadata.images`. Alt графика может быть неполным, поэтому данные нужно проверять вместе с рисунками. Нельзя считать plain text полноценной заменой исходной разметки.

## Запуск

Сохраните отрисованную страницу в HTML после загрузки и раскройте доступные ответы. Требуются Python 3 и конкретный номер задания ОГЭ для этой страницы:

```powershell
python pipelines/shkolkovo/parse.py --html page.html --url 'https://3.shkolkovo.online/catalog/7150?SubTheme=9513' --number 11 --output tasks.json
```

Для профильной математики ЕГЭ добавьте `--exam ege`. Сохранённая браузером страница может ссылаться на SVG в соседней папке `_files`: такие пути сохраняются как `metadata.local_images`, а не превращаются в несуществующие URL. Импортёр разрешает их проверку без записи, но блокирует запись в БД до переноса файлов в доступное хранилище.

Отчёт в stderr перечисляет карточки без обязательных полей; в JSON попадают только записи с адресом, текстом и ответом. Не выводит ошибку для отдельного пропущенного задания: проверьте отчёт перед импортом. Если карточек нет, команда завершается с ошибкой.

Каждый вызов предназначен для одного номера задания с кратким ответом (1–19). Для развёрнутых заданий этот вариант пока не подходит. URL исходной карточки используется как source_url. В `subject` используется `math`, в `exam_type` — `ege` или `oge` по выбранному флагу; код `math` для ОГЭ нужно согласовать с автором БД. В коде актуальной ветки БД пакет называется `backend/pkg/db`.

В папке backend проверить JSON без записи:

```powershell
go run ./cmd/import-shkolkovo --file ../tasks.json
```

Для явной записи в настроенную тестовую БД с применённой миграцией установить `DATABASE_URL` и добавить `--write`. Импортер использует `db.AddTasks`, который обновляет совпадения по паре source_url и content_hash. Реальные задачи и ответы перед записью необходимо проверить; авторские материалы и доступ к ним использовать с учётом условий источника.

Ограничения: нет обхода всех тем/страниц, проверки постоянства SVG или автоматического раскрытия ответов. Разметка источника и формат MathML/LaTeX могут отличаться; точность условий не гарантирована, особенно для alt графиков. Не использовать массово до проверки сохранённого HTML и согласования процесса с командой.
